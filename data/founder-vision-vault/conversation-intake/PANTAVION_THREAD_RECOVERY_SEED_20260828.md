# 11. Translation current truth / reliability blocker

The production translation architecture has provider/model canonicalization, bounded retries, hedged Gateway lanes, a Gateway 429 circuit breaker and private provider failover logic.

However recent production evidence includes real Vercel AI Gateway HTTP 429 rate limiting leading to Pantavion HTTP 503, and the direct private OpenAI path has produced an `invalid_api_key` diagnostic in production.

Therefore reliable bidirectional translation must not be called continuously `VERIFIED_LIVE` until repeated exact-revision production tests demonstrate stable EL->EN and EN->EL behavior without intermittent 503 failures.

Public translation fallback remains intentionally disabled unless explicitly approved.
