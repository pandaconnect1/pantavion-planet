## Purpose
Pressure-test the current leading Pantavion synthesis against adjacent 2024–2026 research and patents. This document narrows the candidate; it does not establish world-first status, patentability, or freedom to operate.

## New negative controls found

The following concepts must NOT be claimed as Pantavion novelty by themselves:

1. **Human-state-centered agentic AI** — 2026 research explicitly proposes agents that model evolving human-state trajectories, longitudinal correctable memory, relational contexts, consent, uncertainty, safety, reversibility and user control.
2. **Context-sensitive judgment about when an agent should act** — 2026 work models scene, context and human-behavior factors and derives principles around timing, intervention depth and agency preservation.
3. **Behaviour-adaptive AI/accessibility** — AURA dynamically adjusts verbosity, speech rate and language complexity using real-time behavioral cues.
4. **Adaptive UI from user + device + environment context** — established research and patents already cover context-of-use, accessibility, platform/device and environment-driven adaptation.
5. **Relationship-centric agent design** — 2026 research already discusses recurring memory-enabled human-agent relationships and autonomy calibration.
6. **Context-aware deterministic policy enforcement for agent capabilities** — existing agent runtimes can apply identity, permission/session-aware deterministic enforcement pipelines.

## Consequence
The broad label **Human-State Governed Capability Fabric** is not sufficiently distinctive if its claim is merely:

`human state + context + memory + relationship + device + consent + adaptive action`

That territory now has substantial adjacent prior art.

## Narrower Pantavion research hypothesis

The strongest remaining Pantavion hypothesis should be tested as a **cross-domain capability transformation protocol**, not as a personal assistant or adaptive UI:

`HUMAN INTENT/NEED`
`+ purpose-bounded context`
`+ relationship/role graph`
`+ scoped continuity/memory`
`+ language/accessibility/device constraints`
`+ jurisdiction/age/consent/rights`
`+ urgency/risk/resilience state`
`-> deterministic admissibility envelope`
`-> capability graph resolution`
`-> existing capability composition OR bounded new capability specification`
`-> specialist multi-kernel execution`
`-> canonical write/event/provenance`
`-> outcome evidence`
`-> reversible improvement candidate`

### Candidate working name
**Pantavion Human Need-to-Capability Protocol (HNCP)**

This name is provisional and carries no novelty claim.

## What may distinguish HNCP if evidence survives

The research target is the *combined protocol* in which:

- a human need is compiled into a machine-executable capability contract rather than only a prompt, task, UI or agent plan;
- deterministic rights/admissibility boundaries are resolved before autonomous execution;
- capability resolution spans multiple Pantavion domains while maintaining hard data-boundary rules;
- absence of a suitable capability can produce a bounded capability specification that enters sandbox/build/evaluation rather than granting an agent arbitrary self-extension;
- the resulting capability remains linked to the originating human intent, evidence, jurisdiction, authority, provenance and rollback state;
- emergency/offline/resilience constraints can change the admissible execution path without changing authoritative truth rules;
- learning/evolution is outcome-evidence-bound and cannot silently rewrite deterministic truth domains.

Each bullet is individually likely to have prior art. Novelty, if any, must be assessed at the protocol/interaction-of-mechanisms level.
