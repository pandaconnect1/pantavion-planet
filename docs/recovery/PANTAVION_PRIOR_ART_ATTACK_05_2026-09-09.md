## Truth rule
This pass deliberately tries to falsify the current HNTCP candidate. It is not a novelty or patentability opinion.

## New prior-art pressure
External research shows that several pieces previously considered potentially differentiating are already active prior art:

1. Human-driven outcome frameworks explicitly make the desired human outcome primary and require AI capabilities to trace to human goals.
2. Persistent-agent systems already preserve goals across interactions and execution substrates, with urgency and agency levels.
3. Goal-oriented dialogue runtimes already model goals, lifecycle state, invalidation and resumption as first-class runtime objects across complex multi-domain conversations.
4. Agent infrastructure protocol work now links Situation -> Intent Request -> Plan -> Operation -> Outcome -> Problem as durable control objects.
5. Capability layers already resolve requested outcomes against available abilities/providers.
6. Internet-agent architecture work already covers intent, capabilities, delegation, authorization, provenance, auditability, revocation and privacy.

Therefore Pantavion MUST NOT claim novelty for: persistent goals; outcome primacy; situation/intent/plan/outcome chains; capability discovery; user-context continuity; agent provenance; or authorization individually.

## Candidate refinement
The defensible research hypothesis must move from `persistent human need` to a more precise mechanism:

### Human Need State Transition Protocol (HNSTP)

Canonical object: a versioned `HumanNeedState`, not an agent goal or application task.

Proposed transition:

`HUMAN_NEED_STATE(n)`
`-> semantic clarification without destroying original expression`
`-> deterministic rights/consent/age/jurisdiction envelope`
`-> relationship + language + accessibility + device + urgency context`
`-> outcome constraints and forbidden effects`
`-> capability resolution (reuse | compose | bounded-create)`
`-> execution through replaceable kernels/agents/providers`
`-> observed outcome + evidence + unresolved delta`
`-> HUMAN_NEED_STATE(n+1)`

The key research question is whether prior art already treats the *human need itself* as a persistent, versioned, rights-bounded state machine whose unresolved delta survives changes of app, agent, provider, device, language, relationship context and jurisdiction, and which can trigger capability composition/creation while preserving deterministic authority boundaries.
