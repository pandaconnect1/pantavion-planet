# Pantavion Professional Universal Conversion Engine

Status: real conversion job foundation with registry, estimates, audit and derivative-only policy.

Purpose:

- Let users choose desired output format.
- Preserve original file as source truth.
- Create derivative conversion jobs.
- Estimate cost before execution.
- Use local adapters only where actually implemented.
- Mark unsupported conversions as provider_required or requires_adapter.
- Never claim fake conversion output.

Professional service model:

Upload original
-> detect format
-> choose desired output
-> show options and cost estimate
-> create conversion job
-> execute only with real adapter or provider
-> store derivative output
-> receipt + SHA256 + audit

DWG/CAD rule:

Original DWG/DXF remains untouched.
Any conversion is a derivative copy.
Derivative output is never original truth.
No layer/color/text/arrow/label removal unless the founder explicitly approves a derivative operation.
CAD conversion requires governed adapter, license, or provider.

Economic model foundation:

- Low-cost local text/JSON/CSV jobs.
- Provider-required document/image/audio/video/CAD jobs.
- Manual quote for professional CAD/DWG conversions.
- Future billing must be connected before production charging.
