# Pantavion Full Ecosystem Live Wave 1

This wave changes the implementation strategy from static/recovery accumulation to parallel canonical completion.

## Active lanes

1. Human + Communication Core backend: privacy, consent, contacts, relationships, blocks, conversations, messages, receipts.
2. Truthful ecosystem gateway: expose the intended global scope while distinguishing LIVE, BUILDING and FOUNDATION surfaces.
3. Recovered donor integration: compare older Social, Translation, Kernel and UI work capability-by-capability before merge.
4. Domain-kernel expansion: central governance with isolated domain kernels and two-layer safety.
5. Revenue classification: DIRECT, INDIRECT, PUBLIC, INSTITUTIONAL, FUTURE/REGULATED.

## Immediate completion gates

- Apply and verify Supabase migration.
- Multi-user and anonymous RLS tests.
- Relationship request/accept APIs.
- Conversation creation and message persistence APIs.
- Realtime subscription and truthful receipts.
- People/Contacts/Requests/Messages visible surfaces.
- Translation-per-message integration.
- Production deploy and two-account live verification.

## Truth rule

A surface may show the final ecosystem breadth, but it must never claim a capability is live unless backend, UI, tests, deployment and production verification all pass.
